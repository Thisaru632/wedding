# 💍 The Wedding of Sachini & Sachin

> An elegant, interactive Sri Lankan Kandyan digital wedding invitation web experience.

---

## ✨ Features

- **Interactive Envelope Opening Experience**: Royal golden wax seal tap-to-open animation.
- **Sri Lankan Cultural Motifs**: Traditional golden mandala rotations, Kandyan couple artwork, and Perahera procession border designs.
- **Ambient Canvas Particles**: Gentle falling stardust and rose petal particle effects.
- **Audio Experience**: Traditional wedding instrumental with an interactive vinyl spinning toggle and animated soundwaves.
- **Story Video Reel**: Cinematics celebrating the couple's journey.
- **Ceremony Timeline**: Interactive event itinerary (Poruwa Ceremony, Lunch & Toast, Cake Cutting, Celebrations).
- **Venue & Directions**: Google Maps integration and location guide for Nature Lanka Hotel, Dehiattakandiya.
- **Photo Gallery & Lightbox**: Interactive gallery with crisp previews and high-resolution zoom view.
- **RSVP & Contact**: Direct RSVP responses and digital guestbook.

---

## 🛠️ Built With

- **HTML5 & Vanilla CSS3** (Custom royal gold & sage aesthetic, responsive layout)
- **Vanilla JavaScript (ES6+)** (Canvas particle physics, interactive audio controller, touch-optimized modal lightbox)
- **Google Fonts** (Cinzel, Playfair Display, Great Vibes, Plus Jakarta Sans)

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or host on GitHub Pages:

1. Clone the repository:
   ```bash
   git clone https://github.com/Thisaru632/wedding.git
   ```
2. Open `index.html` directly or serve via a local web server:
   ```bash
   npx serve .
   ```
